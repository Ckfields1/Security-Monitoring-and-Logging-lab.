# Security Monitoring and Logging Lab

## Overview

This repository documents a hands-on cybersecurity lab I completed as part of my Fundamentals of Information Systems Security course. The lab focused on detecting suspicious activity, analyzing security logs, monitoring network traffic, and protecting system integrity.

## Tools and Technologies

* Windows Event Viewer
* Linux
* Snort
* Tripwire
* rsyslog
* ICMP and network traffic analysis

## Lab Activities

During this lab, I:

* Identified failed login attempts on Windows using Event Viewer.
* Examined failed Linux login attempts through system logs.
* Edited the Linux `rsyslog.conf` configuration file.
* Configured Snort to monitor network activity.
* Generated and analyzed ICMP alerts in the Snort Active Log.
* Configured Snort intrusion-prevention settings.
* Used Tripwire to monitor file integrity.
* Investigated Windows Security Event ID 5061, which records cryptographic operations.

## Skills Demonstrated

* Security log analysis
* Authentication monitoring
* Network traffic monitoring
* Intrusion detection and prevention
* File-integrity monitoring
* Windows and Linux security
* Security-event investigation
